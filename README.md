# Электронный журнал

Веб-система учёта посещаемости, расписания, оценок и зачётов для колледжа, вуза или школы.

Работает локально или на своём сервере. Данные — в SQLite у вас; наружу ничего не уходит без вашей настройки.

Подробная настройка: **[SETUP.md](./SETUP.md)**.

## Стек

| Слой | Технологии |
| --- | --- |
| Runtime | **Node.js 20+** (ES modules) |
| Сервер | Нативный **HTTP** (`server.js`), без Express |
| База | **SQLite** через `better-sqlite3` |
| Расписание | Собственный парсер Excel + визуальный конструктор |
| Excel | **SheetJS (xlsx)** — `.xlsx` / `.xls`, Google Sheets по HTTPS |
| Почта | **Nodemailer** (SMTP, опционально) |
| Клиент | Vanilla **HTML / CSS / JS** (без React/Vue) |
| Шрифт UI | **Unbounded** (Google Fonts) |
| Деплой | systemd + Node на VPS (скрипт `scripts/deploy-remote.mjs`) |

## Возможности

- Группы, ученики, педагоги, предметы
- Расписание: ручная правка и импорт из Excel / Google Sheets
- Визуальный **конструктор парсера** (любая раскладка таблицы)
- Календарь, отметки явки, оценки и зачёты
- Роли: администратор, преподаватель, староста, ученик
- SMTP и Telegram (опционально)
- Адаптив: телефон и компьютер

## Быстрый старт

```bash
npm install
npm run seed:demo
npm start
```

Адрес по умолчанию: `http://127.0.0.1:8787` (см. консоль при старте).

| | |
| --- | --- |
| Логин | `admin` |
| Пароль | `admin123` |

Сразу смените пароль. Переменные окружения — в `.env.example`. Полный гайд — в [SETUP.md](./SETUP.md).

## Структура

```
server.js                 HTTP API
public/                   интерфейс
lib/                      расписание, почта, права, Telegram
lib/schedule/             парсер, планы недель, пресеты
scripts/seed-demo.js      демо без чужих данных
test/                     автотесты
data/                     SQLite (в git не входит)
```

## Скрипты

| Команда | Описание |
| --- | --- |
| `npm start` | Запуск сервера |
| `npm run seed:demo` | Демо-настройки и две пустые группы |
| `npm test` | Тесты |

## Безопасность

- `data/`, загрузки и `.env` не публикуются
- Не коммитьте пароли SMTP, токены ботов и доступы к серверам
- После первого запуска смените пароль администратора
