# Электронный журнал

Веб-система учёта посещаемости, расписания, оценок и зачётов для колледжа, вуза или школы.

Работает локально или на своём сервере. Данные хранятся в SQLite на вашей машине — ничего не уходит «в облако» без вашей настройки.

## Возможности

- **Группы, ученики, педагоги, предметы**
- **Расписание** — ручная правка пар и импорт из Excel / Google Sheets
- **Календарь** — месяц и неделя, отметки явки на парах
- **Оценки и зачёты**
- **Роли**: администратор, преподаватель, староста, ученик
- **SMTP и Telegram** (опционально) — письма и уведомления
- **Адаптивный интерфейс** — телефон и компьютер

## Требования

- Node.js **20+**
- Windows / Linux / macOS

## Быстрый старт

```bash
npm install
npm run seed:demo
npm start
```

Откройте в браузере адрес из консоли (по умолчанию `http://127.0.0.1:3847`).

**Первый вход**

| | |
| --- | --- |
| Логин | `admin` |
| Пароль | `admin123` |

Сразу смените пароль в профиле. Можно задать свои значения через переменные окружения — см. `.env.example`.

## Настройка

1. **Настройки** → название заведения, тип (колледж / вуз / школа), пороги явки.
2. Создайте группы, учеников и предметы.
3. Соберите расписание вручную или подключите Excel / Google Sheets.
4. Выдайте доступы преподавателям, старостам и ученикам.

### Excel / Google Sheets

В настройках можно включить режим таблиц:

- загрузка `.xlsx` / `.xls`
- HTTPS-ссылки на файл или Google Sheets («доступ всем, у кого есть ссылка»)
- визуальный конструктор парсера (недели, дни, ячейки, разделители текста)

Если режим выключен — расписание ведётся только внутри системы.

## Структура проекта

```
server.js          — HTTP API и сервер
public/            — интерфейс (HTML / CSS / JS)
lib/               — расписание, почта, права, Telegram
scripts/           — демо-сид
test/              — автотесты
data/              — база SQLite (создаётся при запуске, в git не входит)
```

## Скрипты

| Команда | Описание |
| --- | --- |
| `npm start` | Запуск сервера |
| `npm run seed:demo` | Демо-настройки и две пустые группы |
| `npm test` | Тесты |

## Безопасность

- База `data/` и загрузки **не публикуются** в репозитории.
- Не коммитьте `.env`, пароли SMTP, токены ботов и доступы к серверам.
- После первого запуска обязательно смените пароль администратора.
