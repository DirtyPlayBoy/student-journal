# Полная инструкция по настройке

Пошаговый гайд: от установки до рабочего расписания, импорта Excel и ролей пользователей.

---

## 1. Установка

### Требования

- **Node.js 20+** (`node -v`)
- Windows, Linux или macOS
- Для продакшена — VPS с открытым портом (часто `80`)

### Локально

```bash
git clone https://github.com/DirtyPlayBoy/student-journal.git
cd student-journal
npm install
cp .env.example .env   # при необходимости отредактируйте
npm run seed:demo
npm start
```

Откройте `http://127.0.0.1:8787` (или порт из `.env` / консоли).

**Первый вход:** `admin` / `admin123` → сразу смените пароль в профиле.

### Переменные окружения (`.env`)

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | HTTP-порт | `8787` |
| `HOST` | Интерфейс прослушивания (если задаёте) | все интерфейсы |
| `ADMIN_USER` | Логин первого админа | `admin` |
| `ADMIN_EMAIL` | Email первого админа | `admin@example.com` |
| `ADMIN_NAME` | Отображаемое имя | `Администратор` |
| `ADMIN_PASSWORD` | Пароль первого админа | `admin123` |
| `RESET_ADMIN=1` | Принудительно сбросить админа при старте | выкл |
| `NODE_ENV` | `production` на сервере | — |

Админ из env создаётся **только если** в базе ещё нет администратора (или при `RESET_ADMIN=1`).

### Windows без терминала

Дважды кликните `start.bat` (нужен установленный Node.js).

## 2. Первичная настройка заведения

1. Войдите как администратор.
2. Откройте **Настройки**.
3. Укажите:
   - **Название** (колледж / вуз / школа)
   - **Подзаголовок** (например: «Журнал посещаемости»)
   - **Тип** учреждения
   - **Пороги явки** (отлично / хорошо / предупреждение) — влияют на цвета статистики
4. Решите про **режим Excel / Google Sheets**:
   - **Включён** — можно грузить таблицы и настраивать парсер
   - **Выключен** — только ручная правка пар внутри системы

Сохраните настройки.

---

## 3. Группы, ученики, педагоги, предметы

### Группы

1. **Группы → Создать группу**
2. Название — как в журнале (например `Группа А-101`)
3. При Excel-режиме позже привяжете **код столбца** из таблицы (может отличаться от названия)

### Ученики

1. Откройте группу или раздел **Ученики**
2. Добавьте ФИО, при необходимости — контакты
3. Можно импортировать списки позже (если появится в вашей сборке) или вводить вручную

### Педагоги

1. **Педагоги → добавить**
2. Привяжите к группам / предметам по необходимости
3. Создайте **пользователя** с ролью «Преподаватель» и тем же доступом к группам

### Предметы

1. **Предметы** внутри группы
2. Названия лучше совпадать с тем, как пишут в Excel — тогда импорт не плодит дубли
3. Кнопка **Дубли** на экране правки пар помогает склеить похожие названия

---

## 4. Расписание вручную (без Excel)

1. **Пары → Правка** (или «Правка сетки» в меню)
2. Выберите **группу** и **неделю** (Верхняя / Нижняя / Все / свои метки)
3. Выберите **день недели** (полные названия: Понедельник…)
4. Заполните карточки пар: предмет, вид, преподаватель, аудитория, время
5. **Замок** — пара не перезапишется из Excel при синхронизации
6. Нажмите **Сохранить …**

Дополнительно:

- **+ Пара** — добавить пару в день
- **+ слот** — ещё одна пустая карточка
- **На нижнюю / На верхнюю** — копировать неделю
- **Очистить** — сбросить неделю (осторожно)
- **Сетка недели** (на широком экране) — клик по клетке открывает пару

Пустой предмет при сохранении **удаляет** пару.

## 5. Excel / Google Sheets — полный цикл

### 5.1. Подготовка таблицы

- Файл `.xlsx` / `.xls` **или** Google Sheets с доступом **«всем, у кого есть ссылка»**
- Только **HTTPS**
- Желательно: дни недели текстом (Понедельник…), номер пары, предмет в одной ячейке или соседних столбцах
- Текст вида `Математика (лекция) преп. Иванова И.И. ауд. 201` парсер разбирает маркерами

### 5.2. Привязка группы

1. Включите Excel-режим в настройках
2. Откройте группу → привязка к коду столбца / ссылке
3. Либо на экране **Правка пар** в панели **Источник Excel**:
   - **Загрузить** — файл или ссылка
   - **Парсер** — визуальный конструктор
   - **Обновить** — ручная сверка

### 5.3. Конструктор парсера (по шагам)

Откройте **Парсер** у нужной группы.

#### Шаг 1 — Источник

- Перетащите `.xlsx` или вставьте ссылку → **Подключить**
- Выберите **лист** таблицы
- Клик по ячейке выделяет её для следующих шагов

#### Шаг 2 — Структура

Тип плана:

| Режим | Когда использовать |
| --- | --- |
| Каждую неделю одинаковое | Одно расписание на все недели |
| Повторяющийся цикл | Верх/низ или N недель по кругу |
| Календарные недели | У каждой недели свои даты |
| Комбинированный | Цикл + отдельные календарные куски |

Задайте:

- число недель в цикле
- **контрольную дату** и номер недели на эту дату (якорь)
- подписи недель (Верхняя / Нижняя / Неделя 1…)

**Сохраните структуру.**

#### Шаг 3 — Дни (самое важное)

Для каждой **недели** и каждого **дня**:

1. Нажмите **Автоопределение** — система попробует угадать столбцы дня / пары / предмета
2. Или выберите пресет:
   - **По заголовку дня** — в столбце встречаются «Понедельник», «Вторник»…
   - **Диапазон** — например `C5:C12` — все ячейки колонки = пары дня
   - **Вручную** — кликаете каждую ячейку предмета
3. Режим **Вручную**: клик по ячейке в сетке → она добавляется как следующая пара
4. Режим **Диапазон**: укажите `A1:A6` или кликните начало и конец
5. **Копировать день →** — правила на следующий день
6. **Копировать неделю →** — все дни на другую неделю плана

Индикатор сверху показывает, какие дни уже размечены.

#### Шаг 4 — Разделители текста

Правила вытаскивают из одной ячейки:

- предмет
- вид занятия `(в скобках)`
- преподавателя после `преп.` / `преподаватель`
- аудиторию после `ауд.` / `кабинет`

Вставьте пример текста → **Проверить на примере** — увидите разбор вживую.  
Можно сбросить к умолчанию или добавить маркеры.

#### Шаг 5 — Время

- **Ручная сетка** — таблица пар 1…N с началом/концом
- **Из Excel** — если в столбце пары уже есть `1. 09:00–10:30`

#### Шаг 6 — Проверка

1. **Проверить парсинг**
2. Смотрите список: день → пары → предмет / преп. / ауд.
3. Если всё верно → **Сохранить настройки и подключить**
4. Замки на парах при импорте не трогаются

### 5.4. Автосинхронизация

В настройках:

- включить автосверку
- интервал в минутах (например 5)

На экране правки видно статус: «Синхронизация · N мин назад».

## 6. Любые виды расписания — что выбрать

| Как выглядит Excel | Что делать в парсере |
| --- | --- |
| Классика: столбец «день», «пара», «дисциплина» | Автоопределение или пресет «По заголовку дня» |
| Верх / низ на разных листах | Структура: цикл 2 недели; у каждой недели свой лист |
| Только верх/низ без дат | Цикл + якорь (контрольная дата) |
| Горизонтальная сетка день×пара | Ручные ячейки или диапазоны по столбцам дней |
| Всё в одной каше текста | Разделители + ручные ячейки |
| Нет Excel | Ручная правка на экране «Правка пар» |

Если автоопределение не сработало — это нормально: разметьте **один день** вручную, скопируйте на остальные, проверьте парсинг, сохраните.

## 7. Пользователи и роли

| Роль | Обычно может |
| --- | --- |
| Администратор | Всё |
| Преподаватель | Свои группы: пары, отметки, оценки |
| Староста | Расписание, явка, статистика своей группы |
| Ученик | Своё расписание / пропуски / оценки (по правам) |

1. **Пользователи → Добавить**
2. Логин, пароль, роль
3. Отметьте доступные группы
4. При необходимости сузьте права галочками

Ученику: роль «Ученик» + его учебная группа.

---

## 8. Отметки, оценки, дневник

- **Отметки** — календарь группы → день → пара → перекличка
- **Оценки / зачёты** — в карточке предмета (если включены в настройках)
- Ученик видит упрощённое меню (расписание, пропуски, профиль)

## 9. Почта (SMTP) и Telegram

### SMTP

В настройках укажите хост, порт, логин, пароль приложения, отправителя.  
Кнопка проверки письма — если доступна в вашей сборке.

### Telegram

1. Создайте бота у `@BotFather`
2. Вставьте токен в настройки
3. Укажите chat id / привязки по инструкции в интерфейсе
4. Команды бота (явка, сегодня) зависят от включённого модуля

## 10. Деплой на VPS (кратко)

```bash
# на машине разработчика, с ssh2 в зависимостях при необходимости
export DEPLOY_HOST=ваш.сервер.ip
export DEPLOY_USER=root
export DEPLOY_PASS='…'
node scripts/deploy-remote.mjs
```

Скрипт заливает файлы в `/opt/student-journal`, ставит зависимости, поднимает **systemd** `student-journal` на порту **80**, **не затирает** существующую `data/journal.db`.

Проверка:

```bash
curl -I http://127.0.0.1/
systemctl status student-journal
```

Рекомендуется поверх поставить HTTPS (Caddy / Nginx + Let's Encrypt).

## 11. Резервные копии

Критично копировать каталог:

```
data/journal.db
```

и при необходимости папку загрузок Excel (если используете локальные source-файлы).

Восстановление: остановить сервис → подставить `journal.db` → запустить снова.

## 12. Частые проблемы

| Симптом | Что проверить |
| --- | --- |
| Не грузится Google Sheets | Доступ «всем по ссылке», HTTPS, не `file://` |
| Парсер видит 0 пар | Шаг «Дни»: размечены ли дни? Верный лист? |
| Предметы-дубли | Кнопка «Дубли», единый стиль названий |
| Excel затёр ручные правки | Поставьте **замок** на пару |
| Неверная верх/низ неделя | Якорь (контрольная дата) в структуре плана |
| Не пускает admin | Свой пароль уже сменён; смотрите `.env` только для *новой* БД |
| Порт занят | Сервер сам пробует следующие порты или задайте `PORT` |
